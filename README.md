# Daiyndal.kz

Каркас сайта для подготовки к НИШ / КТЛ / РФМШ (5–6 класс). Next.js 14 (App Router) + TypeScript + Tailwind CSS.

## Что уже готово (макет, без бэкенда)

- `/` — лендинг: hero с превью рейтинга, пәндер, мүмкіндіктер, тарифы (НИШ/КТЛ/РФМШ), мұғалімдер, CTA
- `/login`, `/register` — формы входа/регистрации (UI, без реальной авторизации)
- `/student` — кабинет ученика: рейтинг, последний балл, ближайший тест, прогресс по предметам
- `/teacher` — кабинет учителя: загрузка материалов, таблица результатов учеников
- `/rating` — общий рейтинг (лидерборд)
- `/tests` — расписание тестов (среда/воскресенье)

Все тексты — на казахском языке. Данные во всех страницах пока **моковые** (захардкожены в коде) — далее подключим базу данных.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Деплой на Vercel

1. Зайти на vercel.com → New Project
2. Выбрать репозиторий `daiyndal-kz` из GitHub
3. Framework Preset определится автоматически как **Next.js**
4. Нажать Deploy — через пару минут сайт будет доступен на `*.vercel.app`
5. Позже можно подключить домен `daiyndal.kz` в Project → Settings → Domains

## Следующие шаги (после каркаса)

1. **База данных и авторизация** — Supabase (Postgres + Auth): таблицы `users`, `students`, `teachers`, `tests`, `questions`, `results`
2. **Реальные формы** — подключить `/login` и `/register` к Supabase Auth, роль (ученик/учитель) при регистрации
3. **Конструктор тестов** — в кабинете учителя: создание вопросов, вариантов ответов, привязка к предмету и дате (среда/воскресенье)
4. **Автосоздание тестов** — cron-задача на Vercel (Vercel Cron Jobs) на среду и воскресенье
5. **Подсчёт рейтинга** — пересчёт после каждого пройденного теста (по предмету и по программе НИШ/КТЛ/РФМШ)
6. **Оплата** — на старте вручную (учитель подтверждает оплату по Kaspi-переводу в кабинете), позже — Kaspi Pay API
7. **Мобильное приложение** — когда сайт стабилен, обернуть через Capacitor (Play Market / App Store) без переписывания кода
